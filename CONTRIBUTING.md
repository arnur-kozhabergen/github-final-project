# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute

1. Open an issue to describe a proposed change or bug.
2. Create a focused branch and make the change.
3. Run `bash simple-interest.sh` with sample inputs to check the calculator.
4. Open a pull request with a concise description of the change.

Please keep contributions respectful and follow the expectations in `CODE_OF_CONDUCT`.
