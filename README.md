# github-final-project

## Project name
**github-final-project** — a small open-source Bash command-line calculator for simple interest.

## What it does
The calculator asks for a principal amount, an annual interest rate (percent), and a time period in years. It computes simple interest with:

`simple interest = principal × rate × time / 100`

## Run it

```bash
bash simple-interest.sh
```

Enter non-negative numbers when prompted. For example, principal `1000`, rate `5`, and time `2` produce simple interest of `100.00`.
